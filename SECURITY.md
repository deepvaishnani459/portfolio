# Security Policy

This repository hosts a static personal portfolio site (HTML/CSS/JS only —
no backend, no database, no user data collection beyond standard GitHub
Pages hosting logs).

## Reporting a Vulnerability
If you discover a security issue (e.g. an XSS vector, a dependency
vulnerability, or exposed sensitive data), please report it privately:

- Open a [private security advisory](../../security/advisories/new) on this
  repository, **or**
- Contact via [LinkedIn](https://www.linkedin.com/in/deepvaishnani459/)

Please do not open a public issue for security reports.

## Scope
This site does not process payments, store credentials, or collect personal
data via forms. Contact actions link out to third-party services
(LinkedIn, ResearchGate, Topmate) which have their own security policies.
